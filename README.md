## Featured Project

### [Real-Time Fraud Detection Platform](https://github.com/CenkAk/Real-Time-Fraud-Detection-Platform)

A production-style fraud detection platform built to explore the full ML lifecycle, from leakage-safe feature engineering and model evaluation to real-time scoring, monitoring, and operational decisioning.

- Trained and compared **Logistic Regression, Random Forest, and XGBoost** models on **249,992 chronologically split transactions**
- Built behavioral and velocity features with point-in-time correctness to reduce data leakage
- Implemented calibrated fraud probabilities and cost-aware **APPROVE / REVIEW / BLOCK** thresholds
- Added delayed-label evaluation, drift monitoring, SHAP-based explainability, and experiment tracking
- Developed a **FastAPI + PostgreSQL** scoring service with **Kafka/Redpanda** event pipelines
- Added **Docker Compose, Prometheus, Grafana, Streamlit**, and automated tests for local observability and investigation workflows

**Stack:** Python · XGBoost · scikit-learn · FastAPI · PostgreSQL · Kafka/Redpanda · MLflow · SHAP · Docker · Prometheus · Grafana
