## Featured project

### [Real-Time Fraud Detection Platform](https://github.com/CenkAk/Real-Time-Fraud-Detection-Platform)

A production-style fraud detection system combining machine learning, streaming, backend engineering, and observability.

- **API & data:** FastAPI, Pydantic, SQLAlchemy, PostgreSQL, Alembic
- **ML & MLOps:** scikit-learn, XGBoost, SHAP, MLflow
- **Streaming:** Redpanda / Kafka-compatible event pipelines
- **Operations:** Docker Compose, Prometheus, Grafana, Streamlit
- **Engineering:** point-in-time features, drift monitoring, model calibration, transactional outbox, and automated tests
